## ✦ About Prometrion

**Prometrion** is a next-generation technology company and digital engineering platform founded by **Rajnikant Gaurav**. Rooted in the spirit of *Prometheus* (bringing foundational fire and tools to humanity) and *Metron* (precision, measurement, and mathematical rigor), Prometrion exists to redefine how digital products, software architectures, and internet businesses are conceived, engineered, and scaled.

## ✦ Our Philosophy: The Prometrion Creed

1. **Subtractive Discipline** — We eliminate unnecessary decoration and bloated JavaScript. Every element, 1px hairline border, and font tracking parameter must earn its place.
2. **Tactile Performance** — Speed is an emotional feature. Zero layout shifts and sub-second Time-To-First-Byte (TTFB) respect user attention and convey software craft.
3. **Autonomous Readiness** — We architect interfaces and data models not only for human clicks, but for seamless integration with autonomous AI agents and multimodal discovery.
4. **Radical Transparency** — Public catalogs, clear sprint timelines, verified customer reviews, and zero hidden retainers.

## ✦ Technology Stack & Engineering Architecture

The Prometrion platform is built with an uncompromising focus on speed, accessibility, and modern aesthetics:

- **Framework**: [Astro 5](https://astro.build/) (Zero-JS Islands architecture, static-first, edge-ready)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/) with custom Geist-inspired stark light/dark tokens, subtle glassmorphic blurs, and sharp `6px` geometry
- **3D Graphics & Visuals**: WebGL / Three.js interactive wireframe globe with spherical coordinate mapping and aurora light effects
- **Type Safety**: 100% TypeScript strict mode
- **Accessibility**: Semantic HTML5, WCAG AA compliant contrast ratios, keyboard-friendly navigation, and reduced-motion fallbacks

## ✦ Development & Deployment

### Prerequisites
- Node.js `18.17.0` or higher
- npm / pnpm / yarn

### Getting Started

```bash
# Clone the repository
git clone https://github.com/prometrion/prometrion.com.git

# Install dependencies
npm install

# Start local development server
npm run dev

# Or run Astro dev server in background
npx astro dev --background
```

### Production Build

```bash
# Type check and build static production bundle
npm run build

# Preview production build locally
npm run preview
```
